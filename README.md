# BOCCHI

Occult Crescent 輔助工具，附帶一般練功用的自動打怪與經驗值追蹤。

⚠️ 台服目前尚未開放 Occult Crescent 地區，下列標註「OCH」的功能要等該地區
上線後才會生效。

## 通用功能

- **自動打怪練功（MobFarmer）**：自動掃描附近怪物並前往攻擊，可整合
  Wrath Combo 執行戰鬥技能。
- **每小時經驗值追蹤（Exp）**。

## Occult Crescent 輔助功能（OCH）

- **藏寶物雷達與自動撿寶**：列出附近寶箱並畫出方位線，可自動巡覽撿取。
- **紅蘿蔔雷達與自動撿拾**：列出附近紅蘿蔔採集點並畫出方位線。
- **貨幣追蹤**：金幣／銀幣每小時獲取量統計。
- **危急事態（Critical Encounters）追蹤與通知**：顯示進度與掉落的異靈碎片、
  筆記、靈魂結晶等。
- **稀有 FATE 提醒**：可個別開關指定稀有 FATE 的通知。
- **Forked Tower**：塔內隊伍狀態追蹤與計時。
- **自動施放強化技能**：依設定自動施放特定 Lost Action 增益效果。

## 指令

- `/bocchi`（別名 `/och`、`/occultcrescenthelper`）：開啟主視窗。
- `/bocchi config` 或 `/bocchi cfg`：開啟設定視窗。
- `/bocchi buff`：套用強化技能。
- `/bocchitp [fate|ce|pot]`：傳送到最近的以太之光，可指定要前往稀有 FATE、
  危急事態或特定持續型 FATE 附近的以太之光。
